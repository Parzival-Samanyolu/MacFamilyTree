# Virtual tree (3D)

Select a person, then open **Virtual tree**.

* **Drag** to orbit, **scroll** to zoom, **right-drag** to pan. **Click** a person to centre the tree on them, **double-click** to open their page.
* Choose *Hourglass*, *Ancestors* or *Descendants*, the number of generations and a theme (Garden, Night sky, Blueprint).
* Names appear for the people nearest to the camera; zoom out to see the whole crown, in to read names. *Show names* turns them off.
* **Reset view** frames the tree again; **Save image** exports a PNG.
* *Auto-rotate* is off by default and is ignored when your system asks for reduced motion.
* **Browse as a list** offers the same people as buttons: activating one flies the camera to that person. This is also the fallback when 3D graphics are unavailable.
