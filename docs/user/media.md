# Media

Open **Media** in the sidebar, or the **Media** tab of a person.

* **Add files** (or drop them on the page): photos, documents (PDF, text), audio and video. Files are stored inside your project file, so a backup contains everything. Adding the same file twice stores it once.
* Click an item to edit its caption, date and place, link it to people, set a profile photo, download or delete it (deletion can be undone).
* Photos with EXIF data offer **suggestions**: the date taken, and the nearest place already in your tree.
* **Not linked to anyone** and **Missing files** help tidy up. Items imported from a GEDCOM file usually have no file attached; open one and use **Attach file**.
* **Slideshow** plays all images; use the arrow keys or *Previous / Next*.

Not available: face tagging, OCR, and thumbnails for audio/video.
