# Getting started

KinTree is a private, offline family-tree workspace. Nothing leaves your computer.

## Start a tree
* **Start a new tree** – a short guided flow: you, then your father and mother. The tree opens afterwards.
* **Import a GEDCOM file** – from any genealogy program (GEDCOM 5.5, 5.5.1 or 7.0). Unrecognised data is kept and written back on export. The **import log** (Import / export) lists every problem with its line number; filter by severity.
* **Explore a sample** – 30 or 2,000 invented people.

## Projects and backups
*Import / export → Project file*: type a path to **open**, **create**, or **save a backup copy**. Projects are single files that save automatically after every change. Each time a project is opened a copy is placed in a `backups` folder next to it (the newest 10 are kept).

## Undo
Every change can be undone and redone (toolbar, `Ctrl/⌘+Z`, `Ctrl/⌘+Shift+Z`) – including merges, deletions and imports of single records. Related changes made in one step (for example *Add father*) undo together.

## Finding people
`Ctrl/⌘+K` opens the command palette: type a name (diacritics and Turkish letters are folded, so `isik` finds *Işık*) or a command such as *Go to Statistics*.
