# Accessibility and appearance

* Everything works from the keyboard; press `?` for the shortcut sheet. Lists, dialogs, menus and tabs follow standard keyboard patterns and have screen-reader labels.
* **Settings** offers light, dark or system theme, a high-contrast mode, text size from 85% to 150%, and English or Turkish.
* Animations respect the system "reduce motion" setting.
* Automated accessibility scans (axe-core) run on every main view in CI.
