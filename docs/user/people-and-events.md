# People, events and relationships

Select a person in **People**. The editor has five tabs.

* **Overview** – sex, reference number, living status (automatic from dates, or forced), privacy, colour label, key facts.
* **Names** – any number of names (birth, married, also-known-as, religious, immigrant) with prefix, given, nickname, surname prefix, surname, suffix. *Make primary* changes which name is shown everywhere.
* **Events & facts** – births, deaths, residences, occupations and more. Dates are free text and understood in many forms: `3 Mar 1850`, `abt 1900`, `bet 1880 and 1890`, `from 1900 to 1910`, `12 Feb 1750/51`, `44 BC`, Julian/Hebrew/French Republican/Hijri via GEDCOM syntax (`@#DJULIAN@ 5 OCT 1582`). A live preview shows how the date was understood. Text that cannot be understood is kept as written and flagged. Events sort by date; drag rows to order undated events. The **Age** column is computed from the birth date.
* **Relationships** – parents (with biological/adopted/foster/step/sealed link type), partners (married, partners, unmarried, …) and children (drag to reorder). *Add relative* creates a person and links them in one step; surnames follow the convention set in **Settings** (father's surname, Turkish soyadı, Spanish double surname, Icelandic patronymic, Slavic gendered endings). *Link existing…* connects people who are already in the tree.
* **Notes & sources** – free-text notes and source citations (choose an existing source or create one, with page/detail).

Deleting a person removes their names, events and links; families remain. Everything is undoable.
